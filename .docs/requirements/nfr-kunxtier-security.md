# kunxtier 安全基线

## 背景

虚拟网承载个人与多人共享流量, 核心中继与卫星中继可能暴露在公网。安全设计围绕密钥边界展开: 节点 WireGuard 私钥、TLS 私钥、admin 凭证、节点凭证、注册与 relay 令牌五类敏感材料各自隔离, 明文不落配置、不进日志。管理权威在核心中继, 但数据面端到端加密不依赖任何中继的可信。

## 目标

- 数据面端到端加密: WireGuard 会话密钥仅存在于通信两端节点, 核心中继与卫星中继均无法解密节点流量
- 卫星中继零知识: 只见密文帧, 无管理权限、无存储
- 管理与信令通道全程 TLS; 默认自签证书免域名依赖, 可选配置域名走 ACME
- CLI / daemon 通道在自签之外叠加证书指纹固定, 防中间人
- 敏感材料 (私钥 / 凭证 / 令牌) 不写入普通配置文件与日志
- 公开端点具备基础暴力防护: 令牌不可枚举, 高频失败尝试被限速

## 功能要求

| 编号 | 说明 | 验收标准 |
| ---- | ---- | -------- |
| NFR-1 | 节点 WireGuard 私钥仅存本机 state 目录 | 文件权限 0600, 任何上行报文与核心中继存储中不含私钥 |
| NFR-2 | 注册令牌一次性且默认有效期受限 | 核心中继仅存令牌哈希, 明文只在签发时展示一次 |
| NFR-3 | admin 凭证独立于设备身份与节点凭证 | admin API 拒绝设备身份与节点凭证调用, 各类凭证不互通 |
| NFR-4 | 日志与错误信息不输出敏感值 | 日志中令牌 / 私钥 / 凭证均为脱敏形式 |
| NFR-5 | 卫星中继零知识 | 卫星无管理数据、无会话密钥处理逻辑, 转发的 WG 帧自带认证 |
| NFR-6 | 传输防中间人 | daemon / CLI 拒绝指纹不匹配的连接; Web 控制台全程 TLS, 自签时依赖浏览器首次信任, 配置域名时走 ACME |
| NFR-7 | 网络组隔离 | 不同网络的成员、地址与令牌在 API、信令与控制台均互不可见、互不可达 |
| NFR-8 | 凭证强度与防枚举 | 注册令牌与节点凭证不小于 128 bit 熵并带校验前缀与网络绑定; 单 bit 猜测在工程上不可行 |
| NFR-9 | 公开端点暴力防护 | 注册端点与 admin 登录按源限速并带失败退避 / 锁定; 未通过认证的 WS 建连有并发与频率上限 |

## 边界与约束

- 首阶段不自建 CA 与证书轮换体系; 证书更换通过重新 init 与重分发指纹完成
- WireGuard 私钥泄露应急 (MVP 无自动轮换): admin 移除节点 + 重签令牌 + 设备重注册
- 不做流量混淆与抗审查 (端口跳跃 / 域前置等)
- 核心中继 SQLite 文件权限收紧, 但不对静态数据做应用层加密, 依赖主机与磁盘安全
- 信令通道与 admin API 均在 TLS 之内, 不接受明文回退
- 限速为单机本地实现, 不引入外部限流组件

## 非目标

- WebPKI / ACME 全自动证书管理 (仅可选支持)
- 双因素认证与 SSO
- 流量分析抵抗
- WAF / DDoS 清洗等边界防护 (依赖主机与网络层)
