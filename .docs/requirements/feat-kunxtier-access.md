# kunxtier 用户与设备接入管理

## 背景

kunxtier 支持多人共享网络。核心中继可承载多个网络组, 用户、令牌与设备都归属于某个网络。不引入注册登录流程, 采用令牌登记制: 管理员为网络内的用户生成一次性注册令牌, 用户凭令牌把设备接入该网络。MVP 中属主是标注字段: 管理与过滤视角按属主组织, 全部管理操作由 admin 执行, 用户没有自助凭证。

## 目标

- 管理员可以创建网络组, 并在网络内创建用户、生成注册令牌
- 新设备凭有效令牌完成注册, 获得节点身份与长期节点凭证
- 设备带属主标注, 控制台与 CLI 按属主过滤展示; 管理操作均需 admin 权限
- 注册令牌一次性且绑定网络; relay 令牌可复用; 均支持撤销
- 管理操作通过 CLI 与 Web 控制台完成, 两者共用核心中继开放的同一套 admin API

## 用户流程 / 页面结构

### 管理员邀请用户

1. admin 按需执行 `kunxtier admin network create` 建新网络组 (核心中继初始化时已建默认网络)
2. admin 执行 `kunxtier admin user create --network <net>`, 在目标网络创建用户
3. admin 执行 `kunxtier admin token issue --user <name>`, 获得绑定该网络的一次性注册令牌
4. 令牌以带外方式交给用户

### 用户接入设备

1. 用户在本机执行 `kunxtier up --token <token> --name <node-name>`
2. daemon 校验令牌, 生成 WireGuard 密钥对, 向核心中继注册公钥
3. 核心中继记录属主, 分配虚拟 IP, 签发节点凭证 (核心仅存哈希), 令牌失效
4. daemon 将节点凭证写入本机 state, 凭它通过后续信令通道的挑战应答校验

### 扩展卫星中继 (可选)

1. admin 执行 `kunxtier admin token issue --type relay`, 签发可复用的 relay 注册令牌
2. 卫星机器凭令牌向核心中继注册, 保持注册长连接, 进入中继列表

### 设备移除

1. admin 执行 `kunxtier admin node remove` (控制台支持按属主过滤定位)
2. 核心中继将该节点从节点表移除, 吊销其节点凭证并广播下线
3. 其他节点更新 peer 列表, 该节点的密钥不再被接受, 旧凭证重连被拒

## 功能要求

| 编号 | 说明 | 验收标准 |
| ---- | ---- | -------- |
| FR-1 | 管理员可创建 / 禁用网络内的用户 | 禁用用户后其名下令牌全部失效, 已注册设备的节点凭证被吊销、重连被拒 |
| FR-2 | 令牌一次性且绑定网络, 支持有效期与撤销 | 重复使用 / 过期 / 撤销 / 跨网的令牌注册被拒绝并返回明确错误 |
| FR-3 | 节点注册时上报公钥, 私钥不离开本机 | 核心中继存储中不存在任何节点私钥 |
| FR-4 | 属主为标注字段: 节点列表 / 详情展示属主, 支持按属主过滤; MVP 无属主自助操作 | 系统中不存在属主凭证; 全部管理操作需 admin 权限 |
| FR-5 | 节点移除后全网生效 | 其他节点在秒级窗口内停止接受其流量; 被移除节点的旧凭证重连被拒 |
| FR-6 | 管理操作均有 admin API 支撑 | CLI 与控制台行为一致, admin API 鉴权独立于设备身份与节点凭证 |
| FR-7 | 节点凭证: 注册成功时由核心签发 (高熵随机), 核心仅存哈希, 信令连接经挑战应答校验 | 无有效凭证的连接冒充 (含仅持 WG 公钥者) 无法建立信令通道 |
| FR-8 | 凭证强度与形态: 注册令牌与节点凭证不小于 128 bit 熵, 带校验前缀; relay 令牌可复用、可撤销 | 令牌格式可被工具校验合法性; relay 令牌撤销后卫星注册 / 重连被拒 |

## 边界与约束

- 无自助注册: 所有用户由管理员创建
- 用户身份仅用于属主标注与过滤, 不参与数据面: 网内所有节点互通
- admin 凭证、节点凭证、各类令牌互相独立, 走 env / 独立文件 / state 目录, 不进普通配置
- 令牌在核心中继仅存哈希, 明文只在签发时展示一次
- WireGuard 私钥泄露的应急路径 (MVP 无自动轮换): admin 移除该节点 + 重签令牌 + 设备重注册
- 扫码加入为移动端预留: 令牌与核心中继地址可编码为二维码, MVP 以文本形式交付

## 非目标

- 属主自助管理 (用户凭证体系、用户登录)
- 完整账号体系 (注册 / 登录 / 会话 / 密码找回)
- 用户间网络隔离与 ACL
- 用户删除 (禁用即可达成隔离目的, 删除为后续低频补充)
- 审计报表与操作日志查询界面
- WireGuard 私钥自动轮换
